# 布娃娃战术小队 · Web MVP

一个纯前端的战术小队小游戏：三人小队穿过 30×30m 的低模森林，探雷、排雷、交火，救起倒下的队友，最后站在电台黄圈里读条 10 秒完成占领。

技术栈：**TypeScript + Vite + Three.js + Rapier3D**。无后端、无外部音频素材（音效由 Web Audio 合成），可直接部署到任意静态服务器。

## 快速开始

```bash
cd WebFormat/ragdoll-tactics-squad
npm install
npm run dev
# 浏览器打开终端输出的地址（默认 http://localhost:5173）
```

生产构建：

```bash
npm run build
npm run preview
```

类型检查：

```bash
npx tsc --noEmit
```

构建产物在 `dist/`，`vite.config.ts` 使用 `base: './'`，可部署到子路径。

## 操作

| 输入 | 功能 |
|---|---|
| 左键点选 / 拖框 | 选择单个 / 多个队员 |
| 右键点地面 | 小队移动（多选时自动展开队形） |
| Shift / Alt + 右键 | 追加移动路径 |
| `1` / `2` / `3` | 快速选中工兵 / 步枪手 / 机枪手 |
| `Space` | 全队停止 |
| `F` | 智能交互：攻击悬停敌人 / 排雷 / 救援倒地队友 |
| `Q` / `E` | 旋转视角；中键拖动也可旋转 |
| 鼠标滚轮 | 缩放（同时改变俯角） |
| `M` | 静音 / 取消静音 |
| `Esc` | 暂停 / 继续；演示模式中退出演示 |

### 一局怎么打

1. 出生点在地图西南角 `(2, 2)`，电台在地图东北角 `(27, 27)`。开局自动选中三人，右键向东北方向移动；多选移动时小队会自动拉开队形，避免一颗雷把全队带走。
2. 工兵前方的探雷器会显示黄色提示，并把地雷从隐藏状态显示出来；工兵接近地雷时会自动停下。再次右键可以强行通过。
3. **选中工兵**，把鼠标移到显示的地雷上按 `F`：工兵自动走到 1.75m 处，读条 3 秒，10% 概率失败（失败会直接引爆）。
4. 敌人会在 8m 内停下开火，不会贴脸。步枪手 / 机枪手会自动索敌开火；按 `F` 悬停敌人可让选中的队员集火并进入射程。
5. 队友倒地后有 10 秒救援窗口。把鼠标移到倒地队友的布娃娃上按 `F`，最近的队友会前去救援；工兵救援 2 秒，其他角色 4 秒。救起后血量为 20。
6. 电台 6m 内还有存活敌人时无法占领。清空守军后，任意一名存活队员站进黄圈读条 10 秒即可通关。

## 已实现

- **相机**：平滑跟随小队质心、滚轮 10–25m 缩放、40°–65° 动态俯角、Q/E 旋转、中键拖动、屏幕震动。相机**不做**防穿模拉近，始终保持在设定距离。
- **输入**：左键点选、拖框、Shift 追加路径、右键移动、快速选人、停止、F 智能交互、暂停、静音、滚轮缩放。
- **单位与物理**：所有单位使用 Rapier 胶囊角色控制器处理地形/掩体碰撞；单位之间做完整软分离，防止穿模；移动、射击、朝向、行走动画联动。
- **AI**：8 名敌人共享启发式状态机（守卫 / 巡逻 / 追击 / 攻击 / 搜索）。15m / 90° 视野、爆炸听觉、射线遮挡、防御区栓绳、在 7.2m 停下并开火；哨兵、巡逻兵、精英三种参数。
- **战斗**：统一 `DamageSystem` 处理双方血量；玩家自动索敌开火；按 F 集火；倒地 / 阵亡 / 流血计时 / 救援。
- **布娃娃**：每个单位倒地或死亡时使用 7 刚体 Rapier 布娃娃（躯干、骨盆、头、四肢 + 球形关节）；爆炸冲量按质量缩放，倒地球员可被 F 救援，救起后恢复模型。
- **地雷**：12 颗（10 固定 + 2 随机）、3m / 120° 探测锥、显示、排雷读条、10% 失败、0.8 秒延迟爆炸、100 伤害、2.5m 半径击飞；探雷器滴滴声随距离加快。
- **UI**：纯 HTML/CSS，保留队友编写的 `StartMenu` / `PauseMenu` / `ResultPanel` / `HUD` 组件；`UIManager` 作为门面统一挂载与切换。左下小队血条、右上音量/静音与电台占领进度、顶部计时/目标、中间 Toast、悬停交互提示、排雷/救援进度条、地雷脉冲、受伤红屏、选中框、暂停与结算面板。
- **音效**：Web Audio 合成探雷器、枪声、地雷点击、爆炸、胜利音效；静音设置写入 `localStorage`。
- **Demo**：`DemoPlayer` 读取 `demoPath01.json`，通过 EventBus 驱动选人、移动、排雷、集火和占领；脚本已按东北角新电台布局更新。
- **菜单 / 暂停 / 结算 / 重新开始 / 返回主菜单** 全流程接通。

## 代码结构

```
src/
  Data/Types.ts          唯一共享类型来源（Vec3、UnitRecord、事件 payload 等）
  core/                  EventBus、GameState、GameLoop、Stats
  app/Game.ts            应用壳：渲染器、输入、菜单、关卡生命周期
  app/Battle.ts          一局任务的组装与更新顺序
  camera/                动态俯角战术相机
  input/                 鼠标/键盘事件
  interaction/           射线拾取、悬停提示
  managers/              小队、移动、工兵探雷器、排雷
  ai/                    敌人 AI
  units/                 单位状态仓库、模型 visual、Rapier 布娃娃
  systems/               伤害、射击、玩家自动战斗、地雷爆炸、救援
  capture/               电台读条
  physics/               Rapier 封装：角色控制器、静态体、布娃娃刚体、射线
  scene/                 关卡加载与低模森林/电台
  effects/               弹道、爆炸、落点标记
  audio/                 Web Audio 合成音效
  ui/                    StartMenu / PauseMenu / ResultPanel / HUD + UIManager 门面
  demo/                  Demo 脚本播放器
```

设计约束：

- 游戏状态只保留在 `UnitStore` / 各系统中，`Game.ts` 不承载具体玩法逻辑。
- 系统间可观察的交互都通过 `eventBus.emit/on`（`moveCommand`、`selectionRequested`、`interactionRequested`、`damage`、`defuse*`、`rescue*`、`capture*`、`gameOver` 等）。
- 所有共享类型定义在 `src/Data/Types.ts`。
- `src/ui/UIManager.ts` 是 UI 门面：实例化并挂载队友的 `StartMenu` / `PauseMenu` / `ResultPanel` / `HUD`，监听它们发出的 `resumeRequest` / `restartRequest` / `mainMenuRequest` 并转发给 `Game`。
- 队友组件和样式保持独立（`src/ui/*.ts`、`src/styles/ui.css`），`UIManager` 只负责组合、显隐和补充计时/Toast/进度条等外围状态。

## 已知取舍 / MVP 限制

- **寻路**：为了先保证可玩，移动是直线移动 + 角色控制器滑动，没有 A* 绕障；树木是实体，必要时右键绕一下。
- **布娃娃表现**：使用 7 个低模刚体部件替换骨骼蒙皮模型，而不是逐骨骼物理；视觉是低模积木风格，但物理、关节、爆炸冲量和救援目标都是真实的 Rapier 刚体。
- **敌人掩体**：当前 AI 有防御区、视野、听觉和射击距离，但没有完整的“找掩体 / 低血量撤退”决策；这是下一轮可扩展点。
- **相机**：为了让树木不把镜头“怼”到角色脸上，已彻底移除防穿模拉近；相机可能被树冠短暂遮挡，需要玩家自行旋转或缩放。
- **电台**：电台位于东北角 `(27, 27)`，与西南出生点 `(2, 2)` 相对；电台附近配置了 2 颗雷和 3 名守军。
- **地雷伤害**：为了确保踩雷一定进入布娃娃，MVP 将反步兵雷伤害设为 **100**（设计文档写 80）。数值在 `src/config/constants.ts` 的 `MINE.damage`。
- **音量**：HUD 右上角提供音量滑杆和静音按钮，设置写入 `localStorage`。
- **Demo**：固定脚本路线，不响应玩家输入；按游戏时间推进，Esc 可退出。当前路线约 67 秒完成。
- 地图、UI、音效均为程序化 Low-poly / 合成，没有引入新的外部素材。
